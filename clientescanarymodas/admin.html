Setup inicial · Generar hash PIN

Solo para configuración inicial. Genera un hash de tu PIN admin para pegarlo como variable de entorno ADMIN_PIN_HASH en Netlify.
✓ Hash generado. Cópialo y pégalo como variable ADMIN_PIN_HASH en tu sitio de Netlify.
⚠️ Tras configurar la variable en Netlify, espera ~30 seg al redeploy y luego entra desde la pantalla principal.

Variables de entorno necesarias en Netlify

Ver lista completa 
GOOGLE_OAUTH_CLIENT_ID     = (mismo del sitio pedidosnuevo)
GOOGLE_OAUTH_CLIENT_SECRET = (mismo del sitio pedidosnuevo)
GOOGLE_OAUTH_REFRESH_TOKEN = (mismo del sitio pedidosnuevo)
CATALOGO_B2B_FOLDER_ID     = (ID de la carpeta "CATALOGO B2B" que tienes que crear en Drive)
SESSION_SECRET             = (string aleatorio largo, distinto del de otros sitios)
ADMIN_PIN_HASH             = (el hash generado arriba)
RESEND_API_KEY             = (mismo del sitio pedidosnuevo)
EMAIL_FROM                 = Canary Modas B2B <pedidos@canarymodas.com>
EMAIL_DESTINATARIOS_B2B    = ["oficina@canarymodas.com","ventascanarymodas@gmail.com"]
